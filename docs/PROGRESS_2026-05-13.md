## 八、关键技术决策记录

| 决策 | 选了 | 没选 | 理由 |
|---|---|---|---|
| Memory 数据结构 | SPO 三元组 | 自由 JSON / 文档库 | 主体维度聚合 + 谓词索引最适合 agent memory |
| 持久化 | JSON / JSONL | SQLite 单库 | 项目规模小，文件方式 diff 友好；FTS 单独用 sqlite |
| Prompt 模板 | 外部 `.md` | 硬编码 f-string | 改 prompt 不动代码、不重启 |
| 别名系统 | 1:1 + canonical_name 链 | 多对一直接绑定 | 1:1 模型简单，等价关系靠 facts 表达 |
| Refactor 节奏 | 阶段性 + 备份 | 一次性大改 | mc-chatbot 在生产跑，需要可 rollback |
| LLM 工具协议 | `[CMD:xxx]` 文本标签 | OpenAI function calling | 跟 mcbot 已有模式一致，模型独立 |

## 九、踩过的坑

- **OpenAI SDK 默认无 timeout**：上游卡住整个 bot 永久阻塞 → 加 30s 超时
- **reasoning model max_tokens 太小 content=None**：`.strip()` 抛 AttributeError 被吞 → 显式 check
- **AI 嘴上说"我调一下"但没真带 [CMD:xxx]**：用户看到"一句卡住" → prompt 加反例 + 智能 retry
- **CQ:at 标签暴力 strip**：AI 拿到没主语的破句子 → 调 OneBot 把 qq 换成群名片
- **Refactor 后 `Path(__file__).parent.parent` 失效**：8 处 `data/*.json` 路径错 → 改 `parents[3]`
- **teammateArr 含全房间玩家不只自己队**：威龙 43 次误识别 → 加 TeamId 过滤
- **vopenid 跳不过历史主玩干员**：user 切了主玩（威龙→疾风），老局误归类 → 改用 own_ops_history 集合
